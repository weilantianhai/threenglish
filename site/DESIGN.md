# Threenglish 介绍页 · 设计说明

## 用户任务

项目展示页原本是纸张、衬线字体和红色批注的“编辑稿”风格。用户要的是：把 App 里的 TS 组件用 HTML 写出来，做成静态页，让展示页和 App 共用一套界面语言，并适当保留实机截图。

## 北极星

**整页像从 App 里截出来的。**

slate 灰底、白色圆角卡、indigo 主色、系统无衬线、Lucide 线性图标。展示页是 App 的延伸，不是给 App 套一张海报皮。

## 这次改了什么

- 弃用纸张色 `#faf9f6`、衬线标题和红色批注线，改用 App 的 `slate-50 / white / indigo-600`。
- 首屏从“被批改的句子”静态图，改成 App 首页对话的 HTML 复刻：用户气泡、优化表达卡、锚点词、语法/为啥换、输入框和难度胶囊。
- 新增“六块界面”界面墙：首页对话、单词卡片、词库、笔记、复习闪卡、我的画像，全部按 App 组件重写。
- 重写词库管理和画像区块：分类胶囊、下载任务、镜像输入、档位条、用词分布、高频错误，都是 App 里的实际组件。
- 新增“这句，是怎么改出来的”滚动叙事：把一句英文从原句、划线、改写、锚点词到拆解，逐块写出来。
- 新增三张 Android 实机截图（词库、单词卡片、词库管理），作为界面墙末尾的证据，不与 HTML 复刻抢主视觉。
- 隐私说明改为更准确的版本：联网只调用 DeepSeek（改写、AI 查词、场景提示），不再宣称“只有一个请求”。

## 滚动叙事分镜

页面滚动总长约 280vh（窄屏 260vh）的“这句，是怎么改出来的”：

- 0–20%：保留原句，标出两处要动的地方；“正在改写…”骨架。
- 20–36%：两处删除线先划掉，改写句写进卡片；卡片下方出现“拆解”占位。
- 36–62%：锚点词与解析埋入；步骤 02 激活。
- 62–100%：拆解块写入，步骤 03 激活；往回滚会倒放。

窄屏保留同一段叙事，缩短滚动距离；只显示当前步骤的文字，卡片内容完整保留。开启“减少动态效果”后不固定、不缩放，所有内容按静态区块直接可读。

## 其它动效

- 首屏：标题、说明、按钮、手机按顺序浮起，手机里的改写卡片逐块出现。
- 区块出场：标题、步骤、界面墙、词库面板、画像卡、隐私条目各自按内容出场；进入屏幕才播，滚回顶部离开后再进入会重播。
- 画像条：滚到画像区时从左侧按数据方向长出来。
- 按下反馈：按钮按下缩到 0.99，导航锚点平滑滚动；链接点击没有假的“成功”提示。

## 关键状态

- 首页对话：完成一组（1/3，已保存）；界面墙展示第 2 句进行中（2/3）。
- 首屏难度胶囊：默认「日常」；可切到 CET-4 / CET-6 / 考研，选中后标签更新并出现操作提示。
- 单词卡片：CET-4 的 `abandon`，含音标、两条释义、搭配、例句。
- 笔记：3 组，其中一组展开摘要并标记已掌握。
- 闪卡：背面（改写 + 锚点解析），对应“复习”主流程。
- 词库管理：下载内容选“标准”，CET-6 分卷 3/6 下载中。
- 画像：B1+，18 句样本；低于 20 句，C1 封顶规则成立。

## 验收与证据

- 桌面 1440×900、平板 768×1024、手机 390×844 与 360×800 都实际截图检查过。
- 静态整页 `?static=1` 最后一次截图没有 lint 提示；动态首屏剩下的提示是未激活步骤的透明度状态和滚动起始的隐藏内容。
- 取证截图属于本地临时文件，未随仓库提交；需要复核时打开 `index.html?static=1` 或重新截图。
- 页面已随 GitHub Pages 发布：`https://weilantianhai.github.io/threenglish/`。

## 已知限制

- APK 链接指向 Releases 固定文件名 `Threenglish-1.1.05.apk`，发版时需要上传同名文件。
- iOS 未提供安装包。
- 三张实机截图取自当前 Android 导出页，字体渲染受本机 WebView 影响，和 HTML 复刻的字形略有差异；保留它们是为了证明界面真实存在，不作为视觉主体。
- 页面是纯静态展示，界面墙里的按钮和输入框不可操作；App 的真实交互以 APK 为准。
